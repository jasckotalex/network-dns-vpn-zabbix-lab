# Документация проекта

Этот файл объединяет адресный план, историю развития лаборатории, команды диагностики и итоговый чек-лист.

## 1. Адресный план

| Сеть или узел | Адрес | Назначение |
|---|---:|---|
| HQ users | `10.10.10.0/24` | пользователи HQ |
| HQ servers | `10.10.20.0/24` | серверы HQ |
| Branch users | `10.20.10.0/24` | пользователи филиала |
| R-HQ ↔ ASA-HQ | `10.254.10.0/30` | транзит HQ |
| R-BRANCH ↔ ASA-BRANCH | `10.254.20.0/30` | транзит Branch |
| ASA-HQ ↔ ISP-Router | `198.51.100.0/30` | внешнее соединение HQ |
| ASA-BRANCH ↔ ISP-Router | `198.51.100.4/30` | внешнее соединение Branch |
| ServerDNS | `10.10.20.10` | BIND9 и Zabbix Agent 2 |
| Server-Zabbix | `10.10.20.20` | Zabbix Server |

## 2. История проекта

### Этап 1 — Сетевая основа

Созданы HQ, Branch, VLAN, маршрутизация и серверные сети.

### Этап 2 — DNS

Установлен BIND9, создана зона `corp.test`, проверены внутренние и внешние DNS-запросы.

### Этап 3 — Безопасность

Добавлены ASA, NAT, ACL и site-to-site VPN между площадками.

### Этап 4 — Zabbix

Установлены Zabbix Server, PostgreSQL, веб-интерфейс и Zabbix Agent 2.

### Этап 5 — Мониторинг

В Zabbix добавлены ServerDNS и локальный Zabbix server. Сбор метрик Linux и графики ServerDNS подтверждены скриншотами. SNMP R-HQ проверен отдельной командой.

## 3. Диагностика

### Проверка маршрута

```bash
ip route get 10.10.20.10
```

### Проверка порта Zabbix Agent

```bash
nc -vz -w 3 10.10.20.10 10050
```

### Проверка службы агента

```bash
systemctl status zabbix-agent2 --no-pager
```

### Проверка SNMP

```bash
snmpget -v2c -c <SNMP_COMMUNITY> 10.10.10.1 1.3.6.1.2.1.1.1.0
```

Вместо `<SNMP_COMMUNITY>` локально подставляется секретное значение. В GitHub оно не публикуется.

### Проверка DNS

```bash
dig @10.10.20.10 dns.corp.test A
dig @10.10.20.10 archive.ubuntu.com A
```

### Проверка веб-интерфейса

```bash
curl -I http://127.0.0.1:8080
```

### Проверка SSH-доступа из Windows

```powershell
Test-NetConnection 10.10.20.20 -Port 22
```
